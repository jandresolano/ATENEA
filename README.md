# ATENEA

ATENEA es un sistema de gestión residencial desarrollado en Python, diseñado
para apoyar la administración de eventos, residentes y procesos internos.

## Requisitos
- Python 3.10 o superior
- MySQL
- Gestor de dependencias pip

## Instalación
Instalar las dependencias del proyecto:
pip install -r requirements.txt

## Ejecución
Ejecutar la aplicación principal:
python app.py
